## GitHub authority

Mode: autonomous

Allowed actions:
- Read and list issues
- Read and list pull requests
- Create issues
- Update issues
- Close issues
- Create branches
- Create commits
- Push branches
- Create pull requests
- Update pull requests
- Merge pull requests

Blocked actions:
- Delete branches
- Force-push
- Create or publish releases
- Deploy
